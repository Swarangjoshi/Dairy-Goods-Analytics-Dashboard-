# 🥛 Dairy Goods Analytics Dashboard

## 📌 Project Overview

This Power BI dashboard analyzes dairy product sales, shelf life, storage conditions, customer buying behavior, and regional performance.

## 📊 Key Insights

* Top selling dairy products
* Regional sales performance
* Customer purchase channels
* Storage condition impact on shelf life
* Highest and lowest shelf life products

## 🛠 Tools Used

* Power BI
* DAX
* Data Modeling
* Data Visualization

## 📁 Dataset

Dairy Goods Dataset
